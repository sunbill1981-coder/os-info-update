# 锐捷云桌面公开能力画像

## 使用边界

这份画像来自锐捷官网公开资料，用于扩展 Windows 情报的风险链路、测试思路和待确认问题。

它只能说明“锐捷产品线具备这种能力”，不能证明“当前项目已启用该能力”。未经现场确认的能力不得提高环境相关度，也不得被表述为已受影响的内部组件。

产品版本、实现路径或支持约束需要进一步核实时，可使用已连接的内部知识库，按 [可选产品知识库](optional-product-knowledge.md) 查询并保留出处。知识库未连接时，本公开画像仍可独立使用；内部回答不能覆盖公开 Windows 事实或代替现场配置确认。

## 官网可确认的产品能力

锐捷将云桌面定位为多架构融合产品，而非只有一种 VDI 形态：

- 桌面架构：VDI、IDV、TCI/VOI 和 VAPP/应用虚拟化。
- 管理面：RCDC 桌面管理平台，覆盖身份、桌面、镜像、策略、数据和应用管理。
- 基础设施：RCCP 超融合云平台、分布式存储、容器化平台服务和 vGPU。
- 桌面交付：桌面池、应用池、影子克隆、镜像下发与统一管理。
- 访问与图形：EST 3.0/HEST 协议、vGPU/FlexGPU，定位覆盖办公、开发和设计场景。
- 终端：ARM、X86、一体机、传统 PC、移动端及第三方终端；IDV 强调离线使用和本地算力，TCI 可涉及 U 盘刷机或 PXE 部署。
- 操作系统：官网概括支持 Windows 主流版本，同时支持 Linux、麒麟 KOS 和统信 UOS；精确版本仍需核对产品兼容性矩阵。

## Windows 风险的产品路由

### VDI

优先关注 Windows 来宾镜像、克隆与桌面池、域加入与登录、远程会话、GPU/显示驱动、USB/外设重定向，以及服务器、存储和网络问题造成的多桌面故障半径。

### IDV

优先关注终端本地 Windows 镜像、启动和驱动、GPU/外设兼容、镜像下发、离线运行、恢复联网后的策略/数据同步，以及不同终端硬件与固件组合。

### TCI/VOI

优先关注 PXE/网络镜像部署、本地启动、UEFI、驱动与硬件透传、传统 PC 利旧，以及统一管理通道中断后的恢复行为。

### VAPP/应用虚拟化

优先关注应用启动与兼容性、跨 Windows 版本迁移、应用池、内外网隔离、文件流转和专业软件授权。

## 对当前情报系统的影响

- 将锐捷官网能力用于扩展“应该询问什么”和“应该测试什么”。
- 不能因为官网支持 vGPU、分布式存储或影子克隆，就认定项目现场使用了它们。
- 锐捷公开资料显示自研 EST/HEST 访问协议，因此不能将所有远程会话问题简单等同为 RDP 问题；需核对实际协议和调用链路。
- 必须由项目人员确认架构、平台版本、Windows 基线和已启用组件，确认后才可进入环境相关度评分。
