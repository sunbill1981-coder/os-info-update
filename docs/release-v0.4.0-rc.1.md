# v0.4.0-rc.1 · 外部风险核验与历史联动预发布

本版本将按时间窗口采集的事件扩展为可持续核验的外部风险线索，提供跨期约束与组合风险记录、隔离运行空间和可更新的历史基线。内部产品资料仍是可选输入，具体 SID、TPM、KB 事故没有专用硬编码规则。此版本标记为 GitHub Pre-release，供后续样板验收和小范围试用准备。

## 主要变化

- 外部核验摘要独立于内部环境相关度筛选；阅读预算可配置，完整事件继续归档。核验建议补充具体动作、需记录的结果和后续判断。
- 新增 debug、trial、production 独立运行空间，默认 trial；旧根目录数据只在显式接纳后进入试跑空间。
- 新增长期约束、跨期组合风险和私有反馈记录。新变化回看所有有效或未知约束，不按报告月份淘汰历史依据；报告展示持续风险、证据时间线、判断变化和下一步。
- 新增候选/已验收公共数据包、覆盖说明、版本与实现指纹、校验值、原子幂等导入、活动基线切换和回退。数据版本与 Skill 版本独立管理，已导出的包不可覆盖。
- 新增隔离历史重评、字段差异与依赖变化复审，以及按月回填计划和可恢复运行账本。
- 真实飞书写入增加用途限制、目标资源绑定和当前报告审阅校验；历史回填不自动发送告警。操作指南、示例和实施清单同步更新。

## 验证

- 217 项单元测试通过，覆盖隔离、跨期共同生效判定、依赖修订复审、导入中断回滚、版本切换、反馈保留及发布校验等行为。
- Skill 结构、Markdown 本地链接与命令参数、公开仓库敏感信息及差异格式检查通过。
- 前期用 814 条冻结事件验证本地导入、重评、HTML 和候选包生成；事件事实指纹保持不变。该试跑数据未验收为正式基线，不包含在本次发布中。

## 使用边界与升级

- 自动跨期召回目前依据共享组件或工作流；隐含依赖、机制关联和共同生效范围仍需人工或智能体评审，不能保证发现全部组合风险。
- 尚无统一旧网页自动重解析、跨期组合风险自动群发或完整消息正文预览。回填失败月份重试全部选定来源，同用途内仍共享来源检查点；历史覆盖须核对各来源实际可取得的原文。
- 真实历史样板、正式公共数据包和小范围周报试点尚未开展。本次不上传运行报告、状态库、真实画像、私有反馈或凭据，不配置定时任务、不发送群消息。
- 升级请按 [README](../README.md) 和 [预发布操作指南](../skills/windows-os-intelligence/references/pre-release-operations.md) 显式接纳旧数据并保留备份；接纳不代表数据已获正式验收。既有候选包保留生成时版本和指纹，不随代码发布改写。

剩余工作见 [实施验收记录](pre-release-implementation.md) 和 [修改清单](pre-release-change-checklist.md)。
